# ONYX BOT — نسخة Render الجاهزة

هذه النسخة مجهزة لتعمل كـ **Render Web Service** مع سيرفر Health صغير على `/health`، بينما بوت تيليجرام يعمل بـ long polling في نفس العملية.

## قبل كل شيء
التوكن الذي ظهر في لقطة الشاشة السابقة يجب اعتباره مكشوفًا. أنشئ **توكنًا جديدًا من BotFather** ولا تضعه في GitHub أو داخل الملفات المرفوعة.

## طريقة الرفع من الجوال

1. فك ضغط المشروع.
2. ارفع الملفات إلى مستودع GitHub جديد. لا ترفع ملف `.env` إن أنشأته محليًا.
3. افتح Render وسجل الدخول.
4. اختر **New → Blueprint** إذا كان `render.yaml` ظاهرًا، أو **New → Web Service** واربط مستودع GitHub.
5. إذا اخترت Web Service يدويًا، اختر **Docker** كبيئة التشغيل. Render سيقرأ `Dockerfile` تلقائيًا.
6. في **Environment** أضف:
   - `BOT_TOKEN` = التوكن الجديد
   - `ADMIN_IDS` = رقم حساب تيليجرام الخاص بك
   - `MAX_FILE_MB` = `49`
   - `COOLDOWN_SECONDS` = `4`
   - `MAX_CONCURRENT_DOWNLOADS` = `2`
   - `REQUIRED_CHANNEL` = اختياري، مثال `@YourChannel`
   - `SUPPORT_URL` = اختياري
7. اضغط Deploy وانتظر حتى يظهر في السجل:
   - `Health server listening on port ...`
   - `ONYX BOT is running`
8. افتح رابط الخدمة في المتصفح. المفترض يظهر النص: `ONYX BOT is running`.
9. افتح البوت في تيليجرام وأرسل `/start`.

## ملاحظات مهمة

- الخطة المجانية في Render قد تدخل في وضع السكون عند عدم وجود زيارات HTTP، لذلك قد يتأخر البوت عند الاستيقاظ. فتح رابط الخدمة يعيد إيقاظها عادةً.
- قاعدة SQLite داخل الخدمة ليست تخزينًا دائمًا على الخطة المجانية؛ الإحصائيات قد تُصفّر بعد إعادة نشر/إعادة إنشاء الحاوية.
- FFmpeg مضمّن في صورة Docker لاستخراج MP3 ودمج الفيديو والصوت.
- المشروع مخصص للروابط العامة والمحتوى الذي تملك حق تنزيله. لا يتجاوز DRM أو المحتوى الخاص/المقفل.
