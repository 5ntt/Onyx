# ✦ ONYX BOT — Social Media Downloader

نسخة مطوّرة من أونيكس بوت لتحميل الوسائط العامة من المواقع التي يدعمها `yt-dlp`، بواجهة عربية وأزرار جودة متعددة.

> استخدم البوت فقط مع المحتوى الذي تملكه أو لديك إذن بتنزيله. المشروع لا يتجاوز DRM، ولا يفك المحتوى الخاص/المقفل، ولا يتحايل على تسجيل الدخول.

## المميزات

- واجهة رئيسية بشعار ONYX وأزرار Inline.
- فيديو: `360p / 480p / 720p / 1080p / Best`.
- صوت: `MP3 128 / 192 / 320 kbps`.
- قراءة عنوان المقطع والناشر والمنصة والمدة قبل التنزيل.
- يدعم عددًا كبيرًا من المواقع العامة حسب دعم `yt-dlp`، مثل YouTube وTikTok وInstagram وX وFacebook وReddit وVimeo وTwitch وPinterest وSoundCloud وغيرها.
- Semaphore لمنع ضغط التنزيلات المتزامنة.
- Cooldown لمقاومة السبام.
- قاعدة SQLite محلية لإحصائيات المستخدمين والتحميلات.
- أمر `/stats` للأدمن.
- اشتراك إجباري اختياري بقناة تيليجرام.
- زر دعم اختياري.
- تنظيف تلقائي للملفات المؤقتة.
- Docker / Docker Compose جاهز.

## المتطلبات

- Python 3.11+
- FFmpeg
- Telegram Bot Token

## التشغيل محليًا

```bash
cp .env.example .env
# عدّل .env وضع التوكن
pip install -r requirements.txt
python bot.py
```

## التشغيل عبر Docker Compose

```bash
cp .env.example .env
# عدّل .env

docker compose up -d --build
```

## إعدادات `.env`

- `BOT_TOKEN`: توكن البوت.
- `MAX_FILE_MB`: أقصى حجم ملف يحاول البوت إرساله.
- `COOLDOWN_SECONDS`: مدة الانتظار بين الطلبات.
- `MAX_CONCURRENT_DOWNLOADS`: عدد التنزيلات المتزامنة.
- `ADMIN_IDS`: آيديات الأدمن مفصولة بفواصل.
- `REQUIRED_CHANNEL`: قناة تيليجرام مثل `@OnyxChannel`، أو اتركها فارغة.
- `SUPPORT_URL`: رابط الدعم الاختياري.

## أوامر البوت

- `/start` — القائمة الرئيسية.
- `/help` — شرح الاستخدام.
- `/stats` — إحصائيات (للأدمن فقط).

## ملاحظات

دعم المواقع ليس ثابتًا؛ منصات التواصل تغيّر أنظمتها باستمرار. عند توقف موقع معيّن، جرّب تحديث `yt-dlp` وإعادة بناء الحاوية.
